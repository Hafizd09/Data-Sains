    Machine Learning

    Dua metode unsupervised learning untuk membandingkan pola kemiripan wilayah.

    Karena dataset tidak memiliki label kelas/target kelayakan, pendekatan clustering dipilih. Pada clustering tidak ada label benar untuk membagi train/test seperti klasifikasi; evaluasi dilakukan dengan metrik internal. Standardisasi fitur diperlukan agar skala PKH dan BPNT sebanding.

    Model 1: K-Means (centroid). Model 2: Agglomerative Hierarchical (jarak Euclidean, single-link). Hasil cluster bisa berubah saat K atau fitur diganti.

    Model 2 — Hierarchical Clustering

    Evaluasi Model

    Silhouette Score untuk kualitas pemisahan cluster dan Elbow Method untuk membantu memilih K.

    Elbow Method — K-Means

    WSS/inertia lebih rendah berarti anggota cluster lebih dekat ke centroid. Pilih “siku” dengan mempertimbangkan konteks, bukan angka saja.

    Silhouette Score

    Rentang -1 sampai 1. Lebih tinggi biasanya menunjukkan cluster lebih terpisah; skor harus dibaca hati-hati pada data kecil.

    Skor model saat ini

    Silhouette adalah evaluasi internal, bukan bukti bahwa kelompok merupakan kategori sosial yang benar. Karena hanya tersedia 18 kelurahan dan dua indikator agregat, hasil bersifat eksploratif. Tidak ada target berlabel untuk menghitung accuracy, precision, recall, atau F1.
